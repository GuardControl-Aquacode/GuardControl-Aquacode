# 🛡️ GuardControl - Sistema de Gestão de Rondas e Segurança em Tempo Real

O **GuardControl** é uma plataforma completa desenvolvida para modernizar, automatizar e monitorizar operações de segurança patrimonial, rondas de vigilantes e gestão de incidentes.

O ecossistema divide-se em três pilares integrados:
1. **App Mobile (Vigilantes):** Registo de pontos de controlo (QR Code/NFC), emissão de alertas de pânico e envio contínuo de posição GPS.
2. **Painel Web (Gestores/Central):** Visualização em tempo real dos vigilantes no mapa, acompanhamento de KPIs, receção de ocorrências e emissão de comunicados.
3. **API Central (Back-end FastAPI):** Servidor unificado responsável por orquestrar a comunicação REST, transmissões em tempo real via WebSockets e integração com banco de dados.
